# 🏥 MediCore — Hospital Management System

> A fully functional Single Page Application (SPA) built for managing complete hospital operations from one unified interface — no page reloads, no multiple files.

Live Demo:  https://shamaim-dev.github.io/MediCore--Management--System/

---

## 🌟 Overview

MediCore is a web-based Hospital Management System designed to streamline all hospital operations from a single dashboard. Built entirely with HTML, CSS, and Vanilla JavaScript — no frameworks, no libraries — just clean, handcrafted code.

The system features a professional dark navy sidebar with a soft gray content area, offering modules for patient management, doctor directory, appointments, departments, medicine inventory, billing, and system settings. Everything works dynamically without any page reload, making it a true Single Page Application.

Key highlights of MediCore include a fully responsive layout that works on mobile and desktop, centered popup forms for adding records, real-time search across all modules, dynamic status badges, and toggle switches for system preferences — all built from scratch without any external framework.

## ✨ Features

### 📊 Dashboard
- Welcome screen with admin name
- Recent patients table with status badges
- Live stats showing Total Patients, Doctors, Appointments, and Departments

### 🧑‍⚕️ Patient Management
- View all registered patients in a clean table
- Add new patient via centered popup form
- Delete patient records with confirmation
- Real-time search by name, doctor, or disease

### 👨‍⚕️ Doctor Directory
- Doctor cards with initials avatar and gradient background
- Specialization and years of experience details
- Available and Busy status badges
- Add new doctors dynamically
- Book Appointment popup with patient name, date, and time
- Real-time search by name or specialization

### 📅 Appointments
- View all appointments in organized table
- Add new appointments via popup form
- Confirmed, Pending, and Cancelled status badges
- Delete appointments with confirmation
- Real-time search

### 🏨 Departments
- Six department cards with colorful icons
- Click any department card to view its doctors list
- Add new departments dynamically
- Back navigation between department grid and detail view

### 💊 Medicine Inventory
- Track medicine stock levels with color coded badges
- In Stock, Low Stock, and Out of Stock status
- Add new medicines with name, category, stock quantity, and expiry date
- Real-time search by medicine name or category

### 💳 Billing and Invoices
- View all patient invoices in a structured table
- Paid, Pending, and Unpaid status badges
- Add new invoices with patient, doctor, amount, date, and status
- Real-time search across all invoice fields

### ⚙️ Settings
- Hospital profile configuration with name, email, phone, city
- Toggle switches for Email Notifications and Auto Backup
- SMS Alerts and Dark Mode preference options
- Save Changes button with confirmation

### 📱 Responsive Design
- Mobile friendly hamburger menu button
- Sidebar slides in and out smoothly on mobile
- All grids and tables adapt to smaller screens
